# UI 设计

## 1. 设计目标

目标用户经常在出发前或户外移动环境中快速查询。界面应安静、紧凑、适合扫描，优先回答“能不能去、主要风险是什么、什么时候去”，而不是把大量专业数字平铺给用户。

首屏直接进入可操作 Dashboard，不建设营销首页。桌面和移动端都要在首个视口显示地点查询、综合结论和最高风险。

## 2. 设计原则

- 结论优先：风险等级、主要原因和建议时间窗先于次要指标。
- 安全冗余：颜色、图标、文字和数值共同表达风险。
- 数据透明：来源、模型、更新时间、缓存状态和置信度可见。
- 活动导向：通过活动分段控件切换海钓、乘船、登岛、露营和摄影视角。
- 布局稳定：加载、切换小时和错误状态不能导致工具栏、指标格和图表跳动。
- 克制视觉：页面分区使用全宽带状或无框布局，卡片只用于独立指标/重复项，圆角不超过 8px，避免卡片嵌套。

## 3. 信息架构

```text
应用外壳
├── 海况 Dashboard（默认）
│   ├── 查询工具栏
│   ├── 综合结论与风险
│   ├── 活动评分
│   ├── 关键指标
│   ├── 逐小时趋势
│   └── 推荐窗口/小时详情
├── 地图选点
├── 收藏地点（登录）
├── 我的地点（登录）
├── 查询历史（登录）
├── 设置（登录）
└── 管理（管理员）
```

桌面端使用窄侧栏或顶部主导航；移动端使用底部导航承载 Dashboard、地图、收藏和设置，管理入口不占主导航。

## 4. Dashboard 布局

### 4.1 查询工具栏

- 地点搜索输入与候选列表。
- 地图图标按钮打开选点视图，使用 Lucide `MapPin`。
- 日期/时间选择器。
- `24h / 72h / 7d` 分段控件。
- 活动分段控件或紧凑菜单。
- 查询命令按钮带 `Search` 图标；刷新使用 `RefreshCw` 图标并提供 Tooltip。

移动端查询控件分两行或抽屉展开，最长地点名换行或省略并提供完整标题，不能覆盖按钮。

当前 `MI-0015` 基础 Dashboard 已先落地预置地点搜索、显式候选选择、UTC 起报时间、`24h / 72h / 7d` 范围和查询提交；`MI-0017` 已展示综合结论、活动评分和主要风险；`MI-0018` 已展示推荐时间窗、风险上升提示和保守返航截止；`MI-0024` 已补齐 Leaflet/OpenStreetMap 全宽地图选点、OSM 署名和经纬度输入降级。活动分段控件和刷新 Tooltip 留待后续阶段补齐。

### 4.2 综合结论区

- 地点名称是主标题，字号克制，不使用营销式超大标题。
- 显示分数、文字等级、风险图标和置信度。
- 展示 1 条结论、最多 3 条主要风险和推荐窗口/返航截止。
- 硬性风险使用固定警示带，禁止被折叠或移到屏幕下方。
- Weather、Marine、Tide 等来源分别显示 Provider、模型、发布时间、抓取时间和缓存状态；某一来源过期时不能被其他新鲜来源的状态遮盖。

### 4.3 活动评分

使用横向可滚动的活动标签或紧凑表格，显示活动图标、分数和文字等级。切换活动时复用同一页面结构，不通过弹窗展示主要结果。

### 4.4 关键指标网格

固定包含风速、阵风、有效波高、浪周期、涌浪、雷暴/对流和能见度。每项显示：

- 熟悉图标和指标名称。
- 当前值、单位和方向。
- 状态文字，如“平稳”“需关注”“高风险”“暂无数据”。
- 点击后打开无嵌套卡片的小时详情抽屉或侧面板。

指标容器使用稳定的最小高度和网格列，加载骨架与真实内容尺寸一致。

### 4.5 趋势与时间窗

- 图表默认显示风速/阵风、浪高/涌浪和综合分三个相关视图，使用 Tabs 切换，避免一次堆叠过多曲线。
- 风险阈值用水平参考线和文字标注，不只用背景颜色。
- Hover/触摸提示显示本地时间、全部可用值、来源和风险规则。
- 推荐窗口使用时间带展示；风险上升点和返航截止使用清晰图标与标签。

当前 `MI-0019` 已实现 Dashboard 内部的趋势 Tabs、推荐窗口时间带和小时详情面板：趋势可在分数、风、浪三组视图间切换，推荐窗口以横向时间带叠加，点击任一小时可查看完整指标、风险贡献和指标来源摘要。第三方 JS 图表库、复杂 Hover Tooltip 和独立抽屉动画仍待后续阶段。

## 5. 其他页面

| 页面 | 核心布局 | 主要状态 |
| --- | --- | --- |
| 地图选点 | 全宽地图 + 底部/侧边确认栏 | 定位拒绝、瓦片失败、选点中 |
| 收藏地点 | 可排序列表，显示最近结论摘要 | 空、加载、删除确认 |
| 我的地点 | 名称/经纬度/默认活动/备注表单 + 可排序列表 | 空、加载、保存校验、再次查询 |

| 设置 | 单位分段控件、默认活动、时区选择 | 保存中、成功、验证失败 |

## 6. 风险视觉规范

| 等级 | 建议颜色 | 图标/文字 |
| --- | --- | --- |
| VeryGood | 绿色 | `CircleCheck` + “非常适宜” |
| Good | 青绿色 | `Check` + “适宜” |
| Moderate | 黄色 | `Info` + “一般” |
| Caution | 橙色 | `TriangleAlert` + “谨慎” |
| Avoid | 红色 | `OctagonAlert` + “不建议” |
| Unknown | 中性灰 | `CircleHelp` + “数据不足” |

主界面使用中性背景、深色正文、绿色/黄色/橙色/红色风险语义和少量海蓝数据强调，避免整页由单一蓝色或深色调主导。

## 7. 组件视觉

- 图标优先使用 Lucide；图标按钮必须有可访问名称和 Tooltip。
- 二元设置使用 Toggle/Checkbox，模式使用 Segmented Control，数值使用输入/Stepper。
- 工具按钮使用熟悉图标，如刷新、收藏、定位、下载，不用带文字的圆角胶囊替代熟悉符号。
- 卡片圆角 <= 8px，阴影轻微；页面区段不做悬浮卡片。
- 字号不随视口连续缩放；使用固定层级和响应式布局换行。

## 8. 响应式设计

| 视口 | 布局 |
| --- | --- |
| 360-599px | 单列；查询两行/抽屉；指标 2 列；底部导航；图表可横向触摸 |
| 600-959px | 2 列主布局；指标 3 列；地图底部面板 |
| 960-1439px | 内容区 + 辅助风险栏；指标 4 列；完整趋势区 |
| >= 1440px | 限制内容最大宽度；增加信息密度，不放大字体 |

所有固定格式组件使用 `minmax`、`aspect-ratio` 或明确最小高度，避免状态变化引发布局位移。

## 9. 页面状态

- 初始：展示查询控件、常用地点和最近一次本地结果，不显示空白大卡片。
- 加载：保持旧结果可见并覆盖局部进度；首次加载使用同尺寸骨架。
- 空数据：明确缺少哪些关键指标，允许改时间/地点。
- 部分数据：可用指标正常展示，缺失项标记“暂无数据”，结论降低置信度。
- 过期缓存：顶部状态带列出具体过期的数据域、数据年龄和刷新操作。
- 错误：在结果区域显示可执行的重试，不只弹 Toast。
- 硬性风险：固定高可见警示，不允许被 AI 摘要弱化。

当前 `MI-0024` 阶段的初始状态展示查询控件、Leaflet/OpenStreetMap 地图选点、坐标输入降级和等待查询说明；查询成功后展示综合评分、活动评分、推荐时间窗、主要风险、趋势 Tabs、小时详情面板、来源、关键指标和逐小时评分表。收藏、潮汐、AI 和第三方 JS 图表仍待后续阶段补齐。

`MI-0026` 已在应用 Header 增加匿名登录/注册入口和登录后的邮箱/退出状态，并增加静态 SSR 登录、注册和无权访问页面。账户页面使用单一紧凑表单、明确错误状态和移动端单列布局；收藏、历史和设置导航仍待对应页面完成后加入。

`MI-0027` 已增加收藏、查询历史、单位设置和管理员运行状态页面。Dashboard 对登录用户加载风速、浪高、温度和默认活动偏好，换算只影响展示；收藏按默认活动再次查询，历史链接恢复地点、起报 UTC、范围和首个活动。360px/桌面 Playwright 布局用例已纳入仓库，但当前环境浏览器下载超时，视觉准出仍待可用浏览器环境执行。

## 10. 可访问性

- 正文与背景符合 WCAG AA 对比度。
- 键盘可操作查询、Tabs、时间选择和图表数据表替代视图。
- 动态结果更新使用适度 `aria-live`，避免每个逐小时点都播报。
- 图表提供摘要和可访问数据表；风险不只依赖颜色。
- 尊重 `prefers-reduced-motion`，不使用无业务意义动画。
