# 评分算法设计

## 1. 设计原则

- 分数用于排序和解释，不能覆盖硬性安全风险。
- 采用保守、可配置、可回放的规则模型作为 v1.0 基线。
- 相同天气对不同活动使用不同修正，避免“一分适用所有场景”。
- 所有阈值是产品初始参数，不声称为通用海事安全标准。

## 2. 总体公式

对每个预报小时和活动：

```text
若触发 Safety Gate：RiskLevel = Avoid，Score = min(ScoreByPenalty, 49)
若关键数据不足：RiskLevel = Unknown，Score = null
否则：
RawScore = 100 - Σ(BasePenalty_i × ActivityMultiplier_i) - Σ(CombinationPenalty_j)
Score = clamp(RawScore, 0, 100)
```

不使用“好天气奖励”抵消危险指标。分数保留两位用于计算，展示时取整。

当前 `MI-0016` 的领域实现先计算单小时综合分；触发 Safety Gate 时 `RiskLevel = Avoid` 且 `Score <= 49`，关键海况数据不足时 `RiskLevel = Unknown` 且 `Score = null`。`MI-0017` 已在综合分之后应用 ActivityMultiplier 生成五类活动分数；Safety Gate 不受乘数降级。

## 3. 初始基础惩罚

### 3.1 平均风速

| 风速 | 基础惩罚 |
| --- | --- |
| <= 3 m/s | 0 |
| > 3 且 <= 5 m/s | 3 |
| > 5 且 < 8 m/s | 10 |
| >= 8 且 < 10 m/s | 20 |
| >= 10 且 < 13 m/s | 35 |
| >= 13 m/s | Safety Gate |

### 3.2 阵风

| 阵风 | 基础惩罚 |
| --- | --- |
| <= 6 m/s | 0 |
| > 6 且 < 9 m/s | 5 |
| >= 9 且 < 12 m/s | 12 |
| >= 12 且 < 17.2 m/s | 25 |
| >= 17.2 m/s | Safety Gate |

平均风速 >= 2 m/s 时，阵风比 > 1.5 追加 8 分惩罚，> 2.0 追加 15 分；平均风很低时以阵风绝对值为主，避免比值失真。

### 3.3 有效波高

| 浪高 | 基础惩罚 |
| --- | --- |
| < 0.3 m | 0 |
| >= 0.3 且 < 0.5 m | 3 |
| >= 0.5 且 < 1.0 m | 12 |
| >= 1.0 且 < 1.5 m | 25 |
| >= 1.5 且 < 2.0 m | 40 |
| >= 2.0 m | Safety Gate |

### 3.4 涌浪高度

| 涌浪 | 基础惩罚 |
| --- | --- |
| < 0.5 m | 0 |
| >= 0.5 且 < 1.0 m | 8 |
| >= 1.0 且 < 1.5 m | 18 |
| >= 1.5 且 < 2.0 m | 30 |
| >= 2.0 m | Safety Gate（岸边/登岛）；其他活动至少高风险 |

### 3.5 周期修正

| 条件 | 修正 |
| --- | --- |
| 周期 < 5 s 且浪高 >= 0.5 m | 船类/登岛追加 10 |
| 周期 5-6 s 且浪高 >= 0.8 m | 船类/登岛追加 5 |
| 涌浪周期 >= 10 s 且涌浪 >= 0.5 m | 岸钓/登岛追加 8 |
| 涌浪周期 >= 12 s 且涌浪 >= 0.8 m | 岸钓/登岛追加 15 |

长周期不直接给正向奖励。对船类是否舒适必须结合浪高、船型和航向，v1.0 不做船型级精细建模。

### 3.6 雷暴、CAPE 和能见度

| 条件 | 惩罚/处理 |
| --- | --- |
| 明确雷暴或官方高影响预警 | Safety Gate |
| CAPE 500-1000 J/kg | 5；存在降水/对流信号时 10 |
| CAPE >= 1000 J/kg | 12；存在其他对流信号时 20 或 Gate |
| 能见度 5-10 km | 船类/摄影 3 |
| 能见度 2-5 km | 船类/登岛 10 |
| 能见度 0.5-2 km | 25 |
| 能见度 < 0.5 km | Safety Gate |

CAPE 缺失不等于 0；单独高 CAPE 不直接等价于雷暴发生。

## 4. 组合风险惩罚

| 规则代码 | 条件示例 | 惩罚 |
| --- | --- | --- |
| `WIND_LOW_WAVE_HIGH` | 风 <= 5 m/s 且浪 >= 1 m | 10，并突出解释 |
| `GUST_VOLATILITY` | 阵风比 > 1.5 且阵风 >= 9 m/s | 8-15 |
| `SHORT_STEEP_WAVE` | 周期 < 5 s 且浪 >= 0.8 m | 10 |
| `SWELL_LONG_PERIOD_SHORE` | 周期 >= 10 s 且涌浪 >= 0.5 m | 岸边活动 8-20 |
| `ONSHORE_EXPOSURE` | 浪向正面冲击已知岸线 | 岸钓/登岛 5-15 |
| `RISK_RISING_FAST` | 未来 2 小时关键指标跨越高风险阈值 | 10，并缩短窗口 |

相同风险不得被基础惩罚和组合规则无上限重复计算。每个维度可配置最大惩罚上限。

当前 `MI-0016` 已实现 `WIND_LOW_WAVE_HIGH`、`GUST_VOLATILITY`、`SHORT_STEEP_WAVE`、`SHORT_STEEP_WAVE_WATCH` 和 `SWELL_LONG_PERIOD_SHORE`。`MI-0018` 已在推荐窗口规划中识别 `RISK_RISING_FAST` 语义并缩短返航建议；`ONSHORE_EXPOSURE` 仍依赖岸线上下文，尚未实现。

## 5. 活动乘数

| 维度 | 岸钓 | 乘船/船钓 | 登岛 | 露营 | 摄影 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 平均风 | 1.0 | 1.2 | 1.1 | 0.8 | 0.6 |
| 阵风 | 1.0 | 1.2 | 1.2 | 1.4 | 0.7 |
| 浪高 | 1.3 | 1.3 | 1.5 | 0.3 | 0.5 |
| 短周期 | 1.0 | 1.4 | 1.3 | 0.0 | 0.2 |
| 长周期涌浪 | 1.5 | 1.0 | 1.5 | 0.2 | 0.5 |
| 能见度 | 0.6 | 1.4 | 1.1 | 0.2 | 1.2 |
| 降雨/雷暴 | 1.0 | 1.0 | 1.0 | 1.4 | 1.2 |

Safety Gate 是否适用于活动由规则单独定义，不能通过乘数降为普通惩罚。

当前 `MI-0017` 已将上表固化为默认 `ActivityProfile`：岸钓、乘船、登岛、露营和摄影分别按维度乘数计算活动分。长周期涌浪映射到独立维度，避免把“周期长”误当成统一舒适信号。

## 6. 等级映射

| 分数 | 风险等级 | 建议 |
| --- | --- | --- |
| 90-100 | VeryGood | 非常适宜 |
| 80-89 | Good | 适宜，关注轻微变化 |
| 70-79 | Moderate | 一般，需要经验和现场复核 |
| 50-69 | Caution | 谨慎，不建议高暴露或经验不足者 |
| 0-49 | Avoid | 不建议 |
| null | Unknown | 数据不足，无法可靠判断 |

## 7. 时间范围聚合

- Dashboard 主分数默认取用户选定时刻，不用 7 天平均值掩盖危险小时。
- 日期概览同时展示当日最佳分、最低分和最严重风险。
- 活动窗口要求连续至少 2 小时满足最低分、无 Gate 且置信度合格。
- 若窗口结束后 1-2 小时风险快速上升，返航截止提前配置的安全缓冲。

当前 `MI-0018` 固化的初始窗口参数：最低连续时长 2 小时，候选置信度下限 0.65；乘船/登岛返航缓冲 60 分钟，岸钓 45 分钟，露营/摄影 30 分钟。窗口后 1-2 小时出现 Safety Gate、活动等级降至 `Caution/Avoid/Unknown`、活动分低于 70 或相对窗口最佳分下降 20 分以上时，视为风险快速上升。

## 8. 置信度与显示

```text
Confidence = Completeness × Freshness × Continuity × ProviderQuality
```

各因子范围 0-1，并设最低下限防止单项轻微缺失造成过度衰减。P0 字段权重大于体验字段。置信度 < 0.65 时不得显示“非常适宜”；关键海况字段同时缺失时返回 `Unknown`。

## 9. 参数版本

算法配置至少包含：

- `version`、`status`、`effectiveFrom`。
- 各指标分段阈值和惩罚。
- Safety Gate、组合规则、活动乘数。
- 置信度权重、推荐窗口最小时长和返航缓冲。
- 参数 Schema 版本和配置哈希。

已发布参数不可原地修改。新版本先回放历史样本和边界用例，再由管理员发布。

当前 `MI-0021` 已在 Domain 层落地 `marine-score-parameters.v1` 参数 Schema、`AlgorithmVersion` 状态机和 `AlgorithmParameterValidator`。发布前校验要求配置哈希与规范化参数载荷一致，Safety Gate、分段惩罚、组合规则、活动 Profile、置信度和推荐窗口参数合法，并确认 `GS-001` 至 `GS-010` 黄金样本全部通过；管理员界面、仓储、默认发布版本唯一性和历史重算仍待后续任务。

## 10. 校准与验证

- 当前 `MI-0020` 已建立覆盖平静、风浪、涌浪、雷暴、低能见度、缺失数据和风险上升时间窗的 GS-001 至 GS-010 黄金样本集。
- 收集用户现场反馈时区分“预报偏差”和“评分规则偏差”。
- 与官方预警和有经验用户判断对比，优先优化漏报高风险问题。
- 记录每版误报/漏报、等级一致率和活动窗口偏差。
- 未形成足够样本前保持规则透明，不引入不可解释机器学习评分。

### 10.1 `MI-0023` 初始阈值评审记录

本次评审以“用户体验样本保持保守，官方高影响天气口径不得漏报”为原则，只修正会造成漏报的边界，不扩大到潮汐、岸线暴露或实时官方预警接入。

| 规则维度 | 外部口径 | 当前决策 |
| --- | --- | --- |
| 阵风 Gate | 中国气象服务公开科普将 8 级大风下界表达为 17.2 m/s；大风/雷雨大风预警说明中，黄色等级通常已涉及 8-9 级平均风或更高阵风，水上作业需要停止或避风 | 将 `WindGustMs` Safety Gate 从 18 m/s 下调到 17.2 m/s，并补边界测试 |
| 有效波高 Gate | 国家海洋预报台/自然资源部海浪警报公开案例中，近岸蓝色或黄色警报已覆盖约 2.0-3.8 m 区间，正式警报以海区、系统和时效综合判定 | 保留 2.0 m Safety Gate。该阈值低于多数组合警报区间下界或落在蓝色案例下界，适合海岛小船和岸边活动的保守辅助判断 |
| 能见度 Gate | 大雾黄色预警说明以 500 m 作为低能见度重要边界，港口、轮渡和交通管理需加强安全措施 | 保留 `< 500 m` Safety Gate，与现有严格小于边界一致 |
| 雷暴 Gate | 雷雨大风预警防御指引要求高空、水上等户外作业停止或避险 | 保留 `Thunderstorm=true` 硬性不建议；实时官方预警 API 另列后续任务 |
