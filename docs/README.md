# Marine Insight 项目文档

## 1. 文档定位

Marine Insight（海岛天气智能分析系统）面向海钓、登岛、乘船、露营、摄影等海岛活动，将风、阵风、海浪、涌浪、雷暴、能见度等分散指标转换为可解释的风险等级、活动评分和建议时间窗。

本目录是项目需求与设计的唯一基线。实现、测试和部署发生变化时，必须同步更新对应文档。

## 3. 当前产品基线

- 产品版本：`v1.0` 规划基线。
- MVP：地点查询、24/72 小时与 7 天预报、海况风险分析、活动评分、趋势图、地图选点。
- 二期：WorldTides 潮汐、日出日落、月相、收藏、历史、AI 自然语言解读。
- 后续：Stormglass 专业数据增强、NOAA/NCEP 数据管线、多模型融合、预警推送和 PWA。
- 技术基线：`.NET 10`、Blazor Web App、ASP.NET Core、PostgreSQL、可选 Redis、Docker。

## 4. 核心设计约束

1. MVP 默认使用 Open-Meteo Weather API + Marine API；Windy 因成本原因不再作为候选 Provider。
2. Stormglass 默认关闭，只在专业数据增强、模型交叉比对或明确预算场景启用；WorldTides 负责潮汐补充。
3. 天气、海浪、潮汐和观测数据按独立来源批次保存，分析结果必须能追溯全部输入批次。
4. 安全结论由确定性规则引擎生成；AI 只负责解释，不得提高风险等级或覆盖硬性禁行规则。
5. 有效波高不是最大浪高；长周期涌浪对礁石、岸边和登岛活动可能更危险，不能简单判定为“更舒适”。
6. 所有结论必须展示数据时间、来源、算法版本和置信度。
7. 系统提供辅助决策，不替代海事部门预警、船方决定和现场安全判断。
