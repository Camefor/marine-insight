# 一、项目背景

对于海钓、露营、海岛旅游、摄影、坐船等活动，仅查看普通天气预报远远不够。

例如：

- 风速只有3m/s，但浪高2米
- 没有下雨，但远洋Swell很大
- 阵风突然增加导致无法返航
- 浪周期很短导致海面剧烈摇晃

目前虽然 Windy 能够展示大量数据，但是：

- 指标分散
- 学习成本高
- 无法自动分析
- 无法快速判断是否适合出海

因此开发本系统。

本系统目标：

> 将多个天气模型、海洋模型的数据进行统一分析，并自动生成适合普通用户理解的海况分析报告。

---

# 二、项目目标

建设一个专业的海岛天气智能分析平台。

支持：

- 海岛
- 海边
- 港口
- 码头
- 渔港
- 岛屿

自动分析：

- 是否适合海钓
- 是否适合露营
- 是否适合摄影
- 是否适合乘船
- 是否存在危险

最终输出：

★★★★★

适宜出海

或者

★★☆☆☆

风险较高
